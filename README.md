# Smart Office Asset & Maintenance Tracker

A comprehensive Full-Stack web application designed to manage office assets, track maintenance status, assign equipment to employees, and handle administrative operations securely.

## Tech Stack

* **Backend:** Python, Django
* **Database:** MySQL / SQLite
* **Frontend:** HTML5, CSS3, Bootstrap 5, Vanilla JavaScript
* **Deployment:** Render

---

## Features

* **Asset Management:** Easily add, update, view, and categorize office assets.
* **Maintenance Tracker:** Monitor repair requests and update maintenance statuses.
* **Employee Assignment:** Track which employee is currently assigned to a specific asset.
* **Admin Dashboard:** Secure role-based control panel for administrators.
